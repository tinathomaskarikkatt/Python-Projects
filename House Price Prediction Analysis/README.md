# 🏡 House Price Prediction using Machine Learning

A Python-based machine learning project that predicts house sale prices using property features such as location, lot area, house condition, construction year, and basement size. The project combines data preprocessing, exploratory data analysis, feature engineering, and predictive modeling to estimate residential property prices.

---

# 📌 Project Overview

This project analyzes a real estate dataset containing both numerical and categorical property features to understand the factors influencing house prices.

---

# 🎯 Project Objectives

- Analyze factors affecting house prices.
- Perform exploratory data analysis (EDA).
- Handle missing values and preprocess the dataset.
- Engineer new features to improve prediction accuracy.

# 💡 Key Insights

The analysis revealed several important findings:

- Newer houses generally command higher sale prices, while older properties tend to be less expensive.
- Houses with better overall condition consistently achieved higher market values.
- Larger lot sizes showed a moderate positive relationship with sale price, although other factors also influenced pricing.
- Log transformation reduced skewness in the target variable, improving suitability for machine learning models.
- Premium residential zoning categories (such as **FV** and **RL**) had significantly higher average house prices than commercial zones.
- Features including **Total Basement Area**, **Year Built**, and **Year Remodeled** showed strong positive correlations with sale price.
- Recently remodeled houses typically achieved higher sale prices, demonstrating the value added through renovation.
